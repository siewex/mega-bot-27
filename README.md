# MEGA-бот — помощник лиги MEGA (Madden NFL 27)

Сидит в группе лиги, отвечает по тегу или на reply, ведёт диалог по ветке ответов, знает регламент с номерами пунктов и механики Madden 27. Чего не знает — отправляет к комиссионерам.

## Структура
```
main.py            — запуск и логика Telegram
config.py          — настройки из переменных окружения
llm.py             — запросы к OpenAI-совместимому API
prompt.py          — характер бота + сборка базы знаний
storage.py         — история веток диалога (SQLite)
textutils.py       — форматирование под Telegram
check_api.py       — проверка ключа и ID моделей
knowledge/         — ВСЯ база знаний, обычные .md файлы
  01_reglament.md          регламент (нумерация пунктов проставлена явно)
  02_liga.md               справка по лиге — дописывайте сюда актуальное
  03_madden27_novoe.md     нововведения Madden 27
  04_reytingi_i_fishki.md  рейтинги (SPD, ACC, COD...) и советы
  05_serye_zony.md         что регламент не покрывает в M27
```

## 1. Создать бота в Telegram
1. @BotFather → `/newbot` → получить токен.
2. `/setprivacy` → **Enable** (по умолчанию). Бот будет видеть только теги, reply на свои сообщения и команды — этого достаточно. Если нужны `TRIGGER_WORDS` (отклик на слово без тега) — поставьте **Disable** и заново добавьте бота в группу.
3. Добавить бота в группу лиги. Написать в группе `/id` — запомнить `chat_id` (для `ALLOWED_CHAT_IDS`) и свой `user_id` (для `ADMIN_IDS`).

## 2. Проверить API локально (по желанию)
```
pip install -r requirements.txt
cp .env.example .env   # заполнить BOT_TOKEN и API_KEY
python check_api.py            # покажет список моделей и сделает тестовый запрос
python main.py
```
Если `check_api.py` пишет, что модель не найдена — возьмите точный ID из выведенного списка и пропишите в `MODEL`.

## 3. Деплой на Bothost
1. Создать проект → тип Telegram / Python (aiogram).
2. Загрузить файлы (через Git-репозиторий или веб-интерфейс). Файл `.env` НЕ загружать — ключи задаются в панели.
3. Главный файл запуска: `main.py`.
4. В разделе переменных окружения указать как минимум `BOT_TOKEN`, `API_KEY`, `COMMISSIONERS`, `ADMIN_IDS`, `ALLOWED_CHAT_IDS` (остальное — см. `.env.example`, у всего есть значения по умолчанию).
5. Запустить и смотреть логи: при старте будет строка `Бот @... запущен`.

## Как обновлять знания
Правите файлы в `knowledge/` (например, СК приняли решение по Tush Push — впишите в `05_serye_zony.md` или `02_liga.md`), заливаете на хостинг и пишете боту `/reload` (или перезапускаете). Текст в `<!-- ... -->` бот не видит.

## Команды
`/help`, `/rules`, `/reset` (в личке), `/id` — всем. `/reload`, `/status` — только ADMIN_IDS.

## Про расход токенов
Регламент и справка передаются в каждом запросе (~15 тыс. токенов на вход). С коэффициентом модели это основная статья расхода. Экономить можно выбором модели (`MODEL`), `DAILY_LIMIT` и `REASONING_EFFORT=low`.
